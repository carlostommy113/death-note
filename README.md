# 📓 Death Note - Diario Secreto Interactivo

Un diario web temático inspirado en **Death Note**, con una pantalla de inicio donde cuelga el collar con el dije de la Death Note que, al ser tocado, abre la libreta en 3D para escribir y guardar pensamientos y recuerdos en el navegador.

---

## 🌟 Características

- **Pantalla de Inicio Atmosférica:**
  - El collar con el dije de la Death Note cuelga y se balancea suavemente como un péndulo.
  - Efecto de partículas de ceniza y niebla flotante estilo Shinigami.
  - Transición cinemática con sonido envolvente sintetizado al tocar el collar o la pantalla.
- **Libreta Death Note en Formato Diario:**
  - Diseño realista de encuadernación en cuero negro y páginas de papel vintage con renglones de cuaderno.
  - **Página izquierda:** Listado de todas tus entradas escritas, contador y buscador en tiempo real.
  - **Página derecha:** Formulario para redactar tus pensamientos con tipografía manuscrita y fecha automática.
- **Persistencia de Datos (LocalStorage):**
  - Todas tus notas se quedan guardadas automáticamente en tu navegador. No se pierden al recargar o cerrar la página.
  - Puedes crear, leer, editar o tachar/eliminar notas.
- **Exportación de Notas:**
  - Botón para descargar una copia de seguridad en formato `.txt`.
- **Reglas "How To Use It":**
  - Modal interactivo con las reglas de uso del diario.
- **Control de Efectos de Sonido:**
  - Sonidos generados en tiempo real mediante la Web Audio API (no requiere archivos externos pesados).
- **100% Responsive:**
  - Se adapta perfectamente a pantallas de computadoras, tablets y teléfonos móviles.

## 🚀 Cómo publicarlo en GitHub y obtener tu link gratis (GitHub Pages)

### Paso 1: Crear un nuevo repositorio en GitHub
1. Entra a [github.com](https://github.com) e inicia sesión con tu cuenta.
2. Haz clic en el botón verde **"New"** (Nuevo repositorio).
3. Ponle un nombre, por ejemplo: `death-note-diario`.
4. Deja la opción en **Public** (Público).
5. **No** marques "Add a README file" (ya tenemos uno listo).
6. Haz clic en **Create repository**.

### Paso 2: Conectar y subir el proyecto
Abre una terminal en esta carpeta y ejecuta los comandos que te proporciona GitHub:

```bash
git remote add origin https://github.com/TU-USUARIO/death-note-diario.git
git branch -M main
git push -u origin main
```
*(Reemplaza `TU-USUARIO` con tu nombre de usuario de GitHub).*

### Paso 3: Activar GitHub Pages para tener tu enlace público
1. En tu repositorio en GitHub, ve a la pestaña **Settings** (Configuración).
2. En el menú de la izquierda, haz clic en **Pages**.
3. En la sección **Branch**, selecciona `main` y la carpeta `/(root)`.
4. Haz clic en el botón **Save** (Guardar).
5. En 1 o 2 minutos, GitHub te mostrará en la parte superior el enlace de tu web:
   `https://TU-USUARIO.github.io/death-note-diario/`

¡Y listo! Podrás abrir el enlace desde tu celular o compartirlo con quien quieras.
